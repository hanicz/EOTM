A category rule reads the partner name a card terminal sends and puts the transaction in a category. The match ignores case and extra spaces, and it only has to appear somewhere in the name — so LIDL catches every branch and store number. Where two rules could both fit, the one higher up this list wins, which is how SIMPLEP mav stays Transport while SIMPLEP dijnet goes to Utilities. Rules run as records are imported; use Re-apply rules to run them over what you already have.
